# 🔐 Savage Auth
A full-stack authentication application built with Node.js and Express, featuring user login, registration, and social authentication. Uses Passport.js and MongoDB to manage user authentication and persistent sessions.

## Features
- User registration and local login
- Social authentication with Google, Facebook, and Twitter
- Session-based authentication using Passport.js
- MongoDB database integration
- Flash messages for authentication feedback
- Dynamic page rendering with EJS


## Tech Stack 
- JavaScript
-  Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- EJS

## Getting Started
1. Clone the repository:
```
git clone https://github.com/CarlyJovon/savage-auth.git
```

2. Navigate into the project:
```
cd savage-auth
```

3. Install dependencies:
```
npm install
```

4. Configure your MongoDB connection and authentication provider credentials.
5. Start the server:
```
npm start
```

6. Open your browser and navigate to:
```
http://localhost:8080
```
